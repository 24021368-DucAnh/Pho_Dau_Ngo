# Art exports

This folder holds versioned, reviewed interchange exports before they are promoted into the Godot runtime asset tree. Prefer GLB/glTF when supported and validated. Keep exports paired with their original source asset ID/version; do not overwrite the only reviewed export.

No model exports are currently present. See `docs/art/TRIPO_ART_PIPELINE.md` for intake, provenance, QA and promotion rules.
